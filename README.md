# Plataforma de Intercambios

## Visión y Alcance
Aplicación web y móvil multiplataforma que permite a los usuarios publicar objetos que desean intercambiar y recibir ofertas de otros interesados. 

## Stack Tecnológico Propuesto
- **Frontend (Web y Móvil):** Flutter (Dart)
- **Backend:** Python (Serverless Framework)
- **Infraestructura y Nube:** AWS (API Gateway, Lambda)
- **Base de Datos:** Amazon DynamoDB

## Sprint 1 - Health Check
Este repositorio contiene el incremento inicial: una interfaz básica en Flutter conectada a un servicio de validación (Health Check) desplegado en AWS, garantizando la comunicación de extremo a extremo entre el cliente y la nube.
