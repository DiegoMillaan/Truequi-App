Truequi

1. Visión
Crear una plataforma multiplataforma (web y móvil) accesible y segura que fomente la economía circular, permitiendo a las personas intercambiar objetos de valor de forma directa, sin necesidad de transacciones monetarias.

2. Usuarios
Personas, desde estudiantes hasta familias, que poseen artículos en buen estado que ya no utilizan y desean adquirir otros bienes de interés (libros, videojuegos, tecnología, ropa) sin gastar dinero, buscando alternativas de consumo sostenible.

3. Problema
La acumulación de objetos útiles pero sin uso en los hogares y la barrera económica para adquirir bienes nuevos. Además, las plataformas actuales están centradas casi exclusivamente en la compraventa, dejando de lado un sistema estructurado, confiable y exclusivo para el trueque directo.

4. Alcance (MVP)
El alcance para esta versión productiva incluye una aplicación web y móvil desplegada en AWS. Permitirá a los usuarios registrarse, publicar artículos con descripciones y fotografías, visualizar un catálogo de objetos disponibles, y enviar o recibir ofertas de intercambio. No se incluirán pasarelas de pago ni envíos logísticos automatizados en esta fase; el enfoque será la conexión entre los usuarios.

5. Flujo Principal

El Usuario A publica un objeto que desea intercambiar en Truequi.

El Usuario B explora la plataforma, encuentra el objeto del Usuario A y decide enviar una oferta ofreciendo a cambio un objeto propio.

El Usuario A recibe la oferta, revisa el objeto propuesto por el Usuario B y la acepta.

El sistema marca el intercambio como acordado y habilita la información de contacto para que ambos usuarios concreten el trueque.
